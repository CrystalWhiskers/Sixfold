# Sixfold

A merge autobattler on a 6×11 board with a neutral centre row. Built with **Godot 4.7.2**.

Battle the computer, play local PvP on one screen, or edit both sides' loadouts.
Each prep phase your units are summoned straight onto the board. Drag a unit onto
an empty tile to move it, onto a twin to merge, or onto another of your units to
swap. Click a unit to read its stats.

## Play

Download the latest Windows zip from the
[Releases page](https://github.com/CrystalWhiskers/Sixfold/releases), unzip it,
and run the `.exe`.

## Run from source

Open `project.godot` in Godot 4.7.2 and press F5.
